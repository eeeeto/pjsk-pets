# ♪ 世界计划 桌宠模拟器 ♪

一个 **Project Sekai（世界计划 彩色舞台）同人性质** 的网页桌宠模拟器。
26 名角色（含虚拟歌姬）以官方 SD Spine 小人的形式住进你的浏览器小房间里。

> ⚠️ 本项目为**同人作品，仅供学习与娱乐**，与 SEGA / Colorful Palette / Craft Egg 无任何关联。
> 模型与美术素材版权归 SEGA / Craft Egg / Colorful Palette / Project Sekai 各原权利方所有，
> 请勿用于商业用途。角色喜恶食物与台词设定为同人创作。

## ✨ 功能

- **角色选择**：开场从 26 名角色中选择角色1（必选）与角色2（可选）；单人居中、双人左右分布
- **房间场景**：奶黄色房间 + 地毯 + 沙发 + 桌子 + 窗户，共 6 种配色主题，也可导入自己的图片作背景
- **随机动作**：每 5~15 秒自动切换待机、大笑、倾听、疑惑、惊讶、散步等动作
- **点击互动**：点击小人会冒出对话框说一句词条库里的颜文字
- **喂食系统**：按同人设定的"喜欢/讨厌食物"喂食，小人会做出开心或生气的反应并冒出表情特效
- **挂件系统**：内置挂件库（自己导入 PNG 存进库里，全角色共用），
  点击库里的挂件进入**摆放模式**——拖到小人身上喜欢的位置，点「确定」才锁定，
  之后自动跟随角色（走路、缩放、水平翻转都同步，挂稳后也还能拖动微调）
- **每角色独立词条库**：设置中只显示生效角色的词条库，可自由增删（角色台词+颜文字）
- **连点彩蛋**：1 分钟内被点 3 次会生气 10~60 秒，期间怎么点都只有生气反应，气消后恢复
- **拍照**：一键把当前场景（含小人、挂件、背景）导出为 PNG
- **设置持久化**：所有设置保存在浏览器 localStorage，刷新不丢失
- **界面主题**：5 种预设 UI 颜色 + 自定义取色器
- **多端适配**：**以移动端为主**优化（触屏拖动、safe-area 手势条避让、响应式布局），
  桌面端同样可用

## 🚀 运行

纯静态网页，无构建步骤：

**方式一：本地服务器（推荐）**

```bash
# 任意静态服务器即可，例如
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

**方式二：直接双击 index.html（file:// 离线打开）**

浏览器的安全策略会拦截 `file://` 页面用 fetch 加载模型文件，
所以需要先生成一次内嵌资源包：

```bash
python3 tools/build_embed.py   # 生成 assets/embed.js（约 9MB）
```

之后双击 `index.html` 即可完全离线游玩（`assets/embed.js` 已在 `.gitignore` 之外的
仓库里的话可一并提交；体积较大时也可不入库，让用户自行生成）。

也可以直接用 GitHub Pages / Cloudflare Pages 等托管部署。

## 📁 目录结构

```
pjsk-pet/
├── index.html            # 入口
├── css/style.css         # 样式（含移动端适配）
├── js/data.js            # 角色 / 食物 / 词条 / 挂件 数据
├── js/app.js             # 主逻辑（渲染、交互、设置）
├── tools/build_embed.py  # 生成 file:// 离线内嵌资源包
└── assets/
    ├── libs/             # pixi.js 7 与 pixi-spine 运行时
    ├── sd_main.skel      # 官方共享 SD 骨骼（Spine 4.1）
    ├── chibis/           # 每个角色的图集（sekai_atlas）
    ├── decos/            # 默认挂件涂鸦（兔耳等）
    └── embed.js          # 内嵌资源包（build_embed.py 生成，离线打开用）
```
